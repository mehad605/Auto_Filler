# 🚀 Auto Filler — Bulk Anki Card Creator

**Auto Filler** is a powerful Anki add-on designed to streamline your flashcard creation workflow. It allows you to create cards instantly by simply copying text or JSON to your clipboard. Whether you are hand-writing cards or using AI like ChatGPT/Claude, Auto Filler handles the heavy lifting of filling fields and switching note types.

## ✨ Why Auto Filler?

Manual card creation is slow. Copying data field by field is tedious. **Auto Filler** eliminates this friction:

- 🤖 **AI-Ready:** Optimized for cards generated by LLMs (ChatGPT, Claude, Gemini).
- ⚡ **Lightning Fast:** "Auto-Create" mode builds hundreds of cards hands-free.
- 📋 **Seamless:** Automatically detects when you copy card data and fills the editor.
- 🧠 **Smart:** Automatically switches note types and maps fields correctly.

---

## 🛠️ How to Install

1.  Open **Anki**.
2.  Go to `Tools` → `Add-ons`.
3.  Place the `Auto_Filler` folder into your Anki add-ons directory.
    - *Usually located at: `%APPDATA%\Anki2\addons21` (Windows) or `~/.local/share/Anki2/addons21` (Linux).*
4.  **Restart Anki.**

## 🎮 How to Use

Auto Filler adds four icons to your Anki "Add Cards" toolbar:

### 1. Choose Your Mode
- **📋 Auto-Fill Mode:** Copy card data → The editor fills automatically. You review it and click **Add**. The next card in your clipboard queue will load automatically.
- **⚡ Auto-Create Mode:** Copy card data → **Everything is created instantly.** Perfect for bulk imports from AI.
- **🗑️ Discard & Skip:** Don't like a card in your queue? Click this to throw it away and load the next one.
- **❓ Help:** Opens the built-in interactive guide.

### 2. Copy Your Data
Auto Filler supports two formats and detects them automatically:

#### **Format A: Custom Text (Human Friendly)**
Great for quickly writing out cards in a text editor.
```text
===!!Basic!!===
==**Front**==
What is the capital of France?
==**Back**==
Paris
==**Tags**==
geography europe
```

#### **Format B: JSON (AI Optimized)**
Copy a JSON array directly from ChatGPT.
```json
[
  {
    "type": "Basic",
    "Front": "What is the capital of Japan?",
    "Back": "Tokyo",
    "tags": ["asia", "geography"]
  }
]
```

## 🤖 AI Prompting Tip
To get the best results from AI, use a prompt like this:

> "Generate 10 Anki flashcards from this text in a JSON array. Return only the JSON array with fields matching my note type."

---

## 💡 Pro Tips
- **Case Sensitivity:** Field names are case-sensitive. "Front" is not the same as "front".
- **Note Types:** Ensure the `type` in your text/JSON matches your Note Type name in Anki.
- **Safety First:** Test with **Auto-Fill** mode before using **Auto-Create** for large batches.
